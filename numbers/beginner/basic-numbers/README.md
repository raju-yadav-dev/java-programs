# 🔢 Number Programs in Java

This repository contains basic **number classification programs in Java** with a short definition, Java logic, and a few examples for each.

---

## 1️⃣ Whole Number

**Definition:** 
Whole numbers are non-negative integers starting from `0`.

**Examples:**  
0 → true  
5 → true  
-3 → false   

## 2️⃣ Prime Number

**Definition:** 
A prime number has exactly two factors: 1 and itself.

**Examples:**  
2 → Prime  
7 → Prime  
9 → Not Prime  
1 → Not Prime  

## 3️⃣ Positive Number

**Definition:** 
A number greater than 0.

**Examples:**  
4.5 → true  
10 → true  
0 → false  
-3 → false  

## 4️⃣ Odd Number

**Definition:** 
A number not divisible by 2.

**Examples:**  
3 → Odd  
7 → Odd  
10 → Not Odd  

## 5️⃣ Negative Number

**Definition:** 
A number less than 0.

**Examples:**  
-2 → true  
-10.5 → true  
0 → false  
8 → false  
-5 → Odd  

## 6️⃣ Natural Number

**Definition:** 
Natural numbers start from 1.

**Examples:**  
1 → true  
6 → true  
0 → false  
-4 → false  

## 7️⃣ Integer Number

**Definition:** 
A number with no decimal part.

**Examples:**  
5.0 → Integer  
-3.0 → Integer  
4.2 → Not Integer  
7.8 → Not Integer  

## 8️⃣ Even Number

**Definition:**
A number divisible by 2.

**Examples:**  
2 → Even  
10 → Even  
7 → Not Even  
-4 → Even  

## 9️⃣ Coprime Number

**Definition:**
Two numbers are coprime if their only common factor is 1.

**Examples:**  
(8, 15) → Coprime  
(7, 13) → Coprime  
(6, 9) → Not Coprime  
(0, 5) → Not Coprime  

## 🔟 Composite Number

**Definition:**
A composite number has more than two factors.

**Examples:**  
4 → Composite  
6 → Composite  
7 → Not Composite  
1 → Not Composite
