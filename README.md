# ☕ Java Programs Repository

This repository contains **Java programs organized section-wise** to help in learning Java and improving logical thinking.

Each program is stored with:
- a **`.java` file** → contains the Java source code  
- a **`.md` file** → explains the concept of the number, definition, and logic  

Currently, the repository focuses on **Number Programs**. More sections will be added later.

### 🔢 Number Programs (Current Section)

*Each number program includes two files:*

### 📄 .java File

- Contains the complete Java source code

- Focuses on clear logic and readability

- Suitable for beginners and students

### 📘 .md File

- Explains what the number is

- Provides definition

- Includes example

- Explains the logic used in the program

### Example:

- Duck_Number.java → Java implementation

- Duck_Number.md → Explanation of Duck Number
